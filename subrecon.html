SubRecon

Automated subdomain enumeration and attack surface mapping tool. Aggregates passive recon from multiple sources, actively probes for exposed API docs and sensitive HTML comments, captures visual evidence with Playwright, and outputs a risk-scored dashboard with trend analysis.

How it works

1
Multi-Source Passive Enumeration

Given a root domain, SubRecon concurrently queries three independent passive sources: HackerTarget for historical DNS records, crt.sh for Certificate Transparency logs (which expose subdomains issued SSL certificates historically), and RapidDNS for bulk DNS enumeration. Results are merged, deduplicated, and validated for liveness.

2
API Documentation Probing

Each live subdomain is probed for exposed API documentation at common paths (/swagger, /api-docs, /openapi.json, /v1/docs, etc.). Exposed Swagger/OpenAPI specs reveal full endpoint inventories, authentication schemes, and request/response models — a common critical finding in security assessments.

3
HTML Source Comment Mining

The HTML comment miner fetches page source and scans comments for patterns matching credentials, internal IP addresses, TODO/FIXME annotations, debug flags, and environment variable leakage. Developers frequently leave sensitive context in HTML comments that are invisible to users but visible in source.

4
Playwright Screenshot Evidence

Playwright navigates to each discovered subdomain with a headless Chromium browser and captures full-page screenshots. This provides visual evidence of the live attack surface — login panels, admin interfaces, staging environments, and internal dashboards — without triggering active scanning alerts.

5
Risk Scoring + Dashboard

Each finding is classified into one of four severity tiers: Critical (exposed credentials or auth bypass), High (exposed API docs), Medium (sensitive HTML comments), Low (informational subdomains). The Streamlit dashboard aggregates findings by severity, renders the screenshot gallery, and tracks trends across multiple scan runs to surface newly appearing or disappearing subdomains.

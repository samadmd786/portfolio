Cloud / AWS Full-Stack Event-Driven Bioinformatics

NucleusCloud

Cloud-native bioinformatics VCF variant processing pipeline on AWS. Accepts genomic VCF files via presigned S3 upload, processes them asynchronously through SQS/SNS-driven microservices, tiers cold storage to Glacier based on subscription level, and emails results via SES - all behind Globus Auth and Stripe billing. Entire stack deployed from a single CloudFormation template.

How it works

1
Authentication via Globus Auth

Researchers authenticate through Globus Auth - a federated identity system trusted by institutions like NIH, XSEDE, and national labs. On successful login, Flask issues a session token and determines the user's tier via Stripe: Basic (150KB VCF upload limit, 5-minute Glacier archival) or Premium (unlimited file sizes, indefinite S3 preservation).

2
Presigned S3 Upload

The Flask backend generates a presigned S3 URL server-side - the VCF file bytes go directly from the browser to S3, bypassing the application server entirely. This eliminates bandwidth bottlenecks and keeps server load near-zero for large genomic variant files. Upload limits are enforced per tier before the presigned URL is issued.

3
SQS + SNS Event Fan-out

S3 upload completion triggers an SQS message picked up by the VCF Analyzer worker, which processes the variant file and pushes results back to S3. SNS fans the completion event to multiple subscribers: the Archiver microservice, the SES Notifier (which emails the researcher on success or failure), and the billing metering endpoint - all independently scalable, zero polling.

4
Step Functions Archival Workflow

SNS triggers a Step Functions state machine with three stages: (1) Validate - checksum verification and format validation, (2) Process - indexing and metadata extraction, (3) Archive - tiered storage migration to S3 Glacier for cost-optimized long-term retention. Each stage is independently retryable with configurable backoff.

5
Glacier Hydration on Demand

Two dedicated microservices handle cold-storage retrieval. The Retriever polls SQS to initiate Glacier retrieval batches; the Restorer Lambda copies the thawed data from Glacier back to hot S3 and generates a presigned download URL. Premium users get automated restoration; Basic-tier users can upgrade via Stripe to unlock it.

6
One-Command Infrastructure

The entire stack - IAM roles, S3 buckets, SQS queues, SNS topics, Lambda functions, Step Functions, VPC networking - is defined in a single CloudFormation template. LocalStack mirrors the AWS environment locally for development. Moto mocks AWS service calls in unit tests, achieving full test coverage without cloud costs.
